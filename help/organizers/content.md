# Collect and approve content

Use **Content** to collect the files and wording needed for a finished program.

## Request a file

Create a request with a plain name, instructions, accepted file types, and due date. Examples include a headshot, slide deck, handout, or final session description.

Speakers see the request in their portal and upload the real file. A replacement creates a new version instead of erasing the earlier one.

## Review versions and comments

Open a submitted file to see its latest version, earlier versions, upload details, and conversation. Download the file when you need to inspect it outside the browser.

Use comments for a specific question or revision request. Choose **Needs changes** when the speaker must act, and explain what should change.

## Approve content

Choose **Approve content** when the public title, description, speaker information, and required files are ready. Approval is separate from scheduling and publication.

An unapproved session stays off the public program even if it has a room and time.

## Remind people in bulk

Filter the deliverables dashboard to incomplete or overdue work, then choose **Send bulk reminders**. ProgramLoom previews the affected group and records the queued messages in Communications.
