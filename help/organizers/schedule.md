# Build the schedule

The agenda builder turns approved sessions into a schedule attendees can use.

## Choose a useful view

- **List** gives a compact overview.
- **Day** shows rooms and time slots.
- **Week** shows the multi-day program.
- **Track** groups sessions by topic.
- **Room** groups sessions by location.

Unscheduled sessions remain visible so they do not disappear from the planning process.

## Place a session

In the day grid, drag a session to a room and time. Before a move that affects an existing calendar invitation or published agenda, ProgramLoom explains the consequences.

If you do not use drag-and-drop, choose **Schedule with form**. It provides the same room, date, start time, and end time controls and works with a keyboard or touch screen.

## Resolve conflicts

ProgramLoom warns when:

- two sessions use the same room at the same time; or
- a speaker is expected in two places at once.

An invalid move does not partly save. Change the room or time, review the result, then choose **Resolve conflict** when the schedule is valid.

## Send calendar invitations

Choose **Send calendar invitation** after a session has a placement. Later changes to the title, date, time, timezone, room, location, description, speaker list, or event details update the existing calendar event rather than creating a new one.

Cancelling a session sends a cancellation and removes it from public views. Rescheduling after cancellation is an explicit organizer action.
