# Manage speaker relationships

The **Speaker CRM** is your organization's shared speaker database. It is not limited to one event, even when you arrive there from an event roster.

## Keep one contact record

The directory stores a person's contact details, biography, tags, custom fields, event history, sessions, notes, and message activity. Search by name, email, company, or job title, then combine company, title, and tag filters.

Use **Clear all filters** to return to the full organization directory.

## Save an audience

Apply filters and choose **Save segment** for a group that should update automatically. Select exact contacts first when you want a fixed curated list. Opening the saved segment shows its current members and count.

## Add a contact to an event

Select a contact and choose **Add to event**. Their reusable profile moves into that event's speaker roster without retyping it. Event-specific onboarding, files, and status remain in the event.

## Handle duplicates

ProgramLoom flags contacts with the same name and different email addresses. Open **Compare & merge**, read the permanent effects, and confirm only when the records represent the same person. Notes, event links, and history move to the retained record.

## Plan outreach

Use the sourcing pipeline to track possible speakers from research through confirmation or future fit. Selected contacts can receive personalized outreach tied to an event, with the result recorded in email history.
