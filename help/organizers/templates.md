# Reuse events and templates

Templates save the parts of a program you want to repeat without carrying over private people or historical work.

## Create from a starter template

From **All events**, choose **Create event**, then select Conference, Meetup, Workshop program, or Community CFP. Review the preview, choose the new name, dates, and timezone, and create the event as a draft.

## Reuse one of your events

You can duplicate an event in the same organization or save its setup as a named organization template. Before creation, ProgramLoom shows exactly what will and will not be copied.

You can copy setup such as CFP fields, review rounds, routing rules, onboarding tasks, file requests, resource pages, message templates, rooms, tracks, formats, content settings, and public-widget appearance.

ProgramLoom does not copy proposals, reviews, decisions, speakers, private notes, uploaded files, message history, calendar records, audit history, or integration secrets by default.

## Check translated dates

When the new event has different dates, ProgramLoom moves relative deadlines where it can do so safely. Review any deadline warning before confirming the new event.

If creation fails, ProgramLoom does not leave a partially usable event behind. Return to the preview, correct the issue, and try again.
