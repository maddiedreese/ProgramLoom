# ProgramLoom evaluator route map

This map fixes the intended production event, persona, and entry point for every evaluator area. Each criterion ID in a listed range inherits the route and persona in its row. The polished evidence event is **ProgramLoom Production Readiness** (`5c33f61d-3af6-41ff-8b2e-6268181001f8`). Disposable failure, conflict, and cancellation records remain visibly labeled and outside its published program.
